# PWOTEKSYON 509

Yon aplikasyon web pwogresif (PWA) ki enstalab, pòte pa **CAPRI** — modil prevansyon ak alèt pou tantativ ak siyalman anlèvman an Ayiti.

**⚠️ Faz aktyèl : konsèp/MVP.** Tout kontni (siyalman, nimewo kontak) make kòm egzanp fiktif jiskaske yo verifye epi valide legalman ak sou plan sekirite.

## Prensip kle
- Yon **siyalman** pa menm bagay ak yon **alèt konfime**.
- Okenn sitwayen pa ka pibliye oswa make pwòp rapò li kòm "konfime" — sèl operatè abilite apre verifikasyon.
- Pa gen idantite viktim, kowòdone egzak, ni detay negosyasyon ki janm pibliye.

## Devlopman lokal
Louvri `index.html` dirèkteman nan yon navigatè, oswa sèvi l ak nenpòt sèvè estatik:

```
npx serve .
```

## Deplwaman
Deplwaye via GitHub Pages dirèkteman soti nan branch `main`.
